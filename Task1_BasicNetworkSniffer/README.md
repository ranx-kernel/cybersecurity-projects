🛡️ Task 1 — Advanced Network Sniffer Dashboard

📌 Project Overview

This project is an Advanced Network Sniffer Dashboard developed using Python during the CodeAlpha Cyber Security Internship.

The application captures and analyzes live network traffic packets in real time using Scapy and displays them through a GUI-based cybersecurity dashboard.

The project helps in understanding:

Network communication

Packet flow

Protocol analysis

Real-time traffic monitoring

Cybersecurity monitoring concepts


🚀 Features

✅ Live Packet Capturing

✅ GUI-Based Cybersecurity Dashboard

✅ Real-Time Traffic Monitoring

✅ TCP / UDP / ICMP Protocol Detection

✅ Source & Destination IP Analysis

✅ Port Analysis

✅ Packet Statistics Dashboard

✅ Start & Stop Sniffing Controls

✅ Scrollable Packet Logs

✅ CSV Packet Logging

✅ Dark-Themed Security Interface
