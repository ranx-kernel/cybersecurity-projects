# Cybersecurity Projects Portfolio

## Overview

This repository contains multiple cybersecurity projects developed to demonstrate practical skills in networking, application security, secure coding, vulnerability assessment, and cybersecurity awareness.

The projects focus on real-world cybersecurity concepts including:

* Network Traffic Analysis
* Phishing Awareness
* Secure Coding Practices
* Vulnerability Assessment
* Application Security (AppSec)
* Security Visualization

---

# Projects Included

## Task 1 — Basic Network Sniffer

A Python-based network packet sniffer developed using Scapy to monitor and analyze network traffic.

### Features

* Packet Capture
* Protocol Analysis
* Source and Destination IP Monitoring
* Network Traffic Inspection

### Technologies Used

* Python
* Scapy
* Networking Concepts

---

## Task 2 — Phishing Awareness Project

A cybersecurity awareness project designed to educate users about phishing attacks, suspicious links, and social engineering threats.

### Features

* Phishing Awareness Interface
* Security Awareness Concepts
* Suspicious Link Detection
* Educational Security Design

### Technologies Used

* Python
* UI/UX Design
* Cybersecurity Awareness Concepts

---

## Task 3 — Advanced Secure Coding Review & Vulnerability Assessment Platform

An advanced Application Security (AppSec) project demonstrating secure coding review, vulnerability analysis, OWASP mapping, and security dashboard visualization.

### Features

* Vulnerable Flask Web Application
* Static Security Analysis using Bandit
* OWASP Top 10 Vulnerability Detection
* Advanced Security Dashboard
* Vulnerability Severity Analytics
* Secure Remediation Workflow

### Vulnerabilities Identified

* SQL Injection
* Command Injection
* Hardcoded Secrets
* Flask Debug Mode Exposure

### Technologies Used

* Python
* Flask
* Bandit
* Streamlit
* Plotly
* SQLite
