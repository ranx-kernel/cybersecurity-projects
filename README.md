# CodeAlpha Basic Network Sniffer

## 📌 Project Overview
This project is a Python-based Network Sniffer developed using Scapy during the CodeAlpha Cyber Security Internship.

The tool captures live network packets and analyzes:
- Source IP Address
- Destination IP Address
- Protocol Type
- Source and Destination Ports
- Packet Payload Preview

It helps understand how network communication works in real time.

---

## 🚀 Features
✅ Live Packet Capturing  
✅ TCP / UDP / ICMP Detection  
✅ Source & Destination IP Tracking  
✅ Port Analysis  
✅ Payload Preview  
✅ Packet Counter  
✅ Packet Logging to File  
✅ Colorful Terminal Output
