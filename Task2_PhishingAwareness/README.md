# Phishing Awareness Training

A cybersecurity awareness project developed for the CodeAlpha Internship Program.

## Project Overview

This project educates users about phishing attacks, fake websites, phishing emails, and social engineering tactics. It also provides safety tips and an interactive quiz to improve cybersecurity awareness.

## Features

- Modern Cybersecurity UI
- Phishing Email Examples
- Fake Website Detection
- Social Engineering Awareness
- Safety Tips
- Interactive Quiz
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
